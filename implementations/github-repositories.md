# GitHub Implementations

Five existing implementations directly tied to papers or models discussed in the review, selected for documentation quality, recent activity, and direct connection to a published paper (per the assignment's selection criteria).

- **weihao1115/MMLU-ProX** — [github.com/weihao1115/MMLU-ProX](https://github.com/weihao1115/MMLU-ProX)
  What it implements: The official MMLU-ProX benchmark and evaluation pipeline (29 languages, EMNLP 2025).
  Why relevant: Directly implements the benchmark responsible for the paper's central cross-lingual accuracy-gap evidence; actively maintained with 2025 updates.

- **google-research/xtreme** — [github.com/google-research/xtreme](https://github.com/google-research/xtreme)
  What it implements: The XTREME cross-lingual benchmark suite (40 languages, 9 tasks).
  Why relevant: The foundational cross-lingual evaluation framework referenced in Section 2.2.

- **facebookresearch/llama** — [github.com/facebookresearch/llama](https://github.com/facebookresearch/llama)
  What it implements: Official LLaMA model release and inference code.
  Why relevant: One of the general-purpose LLMs whose emergent multilingual competence is discussed in Section 2.1.

- **google-research/multilingual-t5** — [github.com/google-research/multilingual-t5](https://github.com/google-research/multilingual-t5)
  What it implements: Official mT5 training and fine-tuning code.
  Why relevant: Reference implementation of the foundational multilingual text-to-text architecture discussed in Section 2.1.

- **bigscience-workshop/Megatron-DeepSpeed** — [github.com/bigscience-workshop/Megatron-DeepSpeed](https://github.com/bigscience-workshop/Megatron-DeepSpeed)
  What it implements: The training codebase used to train BLOOM (176B-parameter multilingual model).
  Why relevant: Documents the engineering behind the openly released multilingual model discussed in Section 2.1; connected to a large, well-documented international research collaboration.
