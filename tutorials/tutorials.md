# Tutorials and Learning Resources

Five authoritative resources for learning the underlying concepts (multilingual NLP, retrieval-augmented generation, and benchmark evaluation) used throughout the paper.

- **Hugging Face NLP Course** — [huggingface.co/learn/nlp-course](https://huggingface.co/learn/nlp-course)
  Free, hands-on course covering transformer models, tokenization, and multilingual fine-tuning with the Transformers library.

- **ACL Anthology** — [aclanthology.org](https://aclanthology.org/)
  The primary open-access archive for computational linguistics and NLP research, including nearly all multilingual-benchmark papers cited in this repository.

- **Hugging Face Transformers Documentation** — [huggingface.co/docs/transformers](https://huggingface.co/docs/transformers)
  Official reference documentation for loading, fine-tuning, and evaluating multilingual models (mT5, BLOOM, LLaMA, etc.).

- **EleutherAI lm-evaluation-harness documentation** — [github.com/EleutherAI/lm-evaluation-harness/blob/main/README.md](https://github.com/EleutherAI/lm-evaluation-harness/blob/main/README.md)
  Practical guide to running standardized, reproducible LLM benchmarks, including multilingual task suites.

- **Papers with Code — Multilingual NLP** — [paperswithcode.com/task/multilingual-nlp](https://paperswithcode.com/task/multilingual-nlp)
  Continuously updated leaderboard and paper index for multilingual NLP tasks and benchmarks.
